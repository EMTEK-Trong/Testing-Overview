# SDV Testing Strategy – Key Principles 

--- 

## 1. Shift-Left & Continuous Testing 

- SDV apps evolve in fast, iterative cycles   
- Traditional late-stage testing is too slow & costly   
- → Adopt **Shift-Left**   
- → Enable **Continuous Testing & Validation across all layers** 

--- 

## 2. Virtualization is Mandatory 

- Primary validation via: 
  - **V-ECU** 
  - **SiL (Software-in-the-Loop)** 

- Hardware role: 
  - Confirm behavior   
  - Validate assumptions   
- → Faster, scalable, cost-efficient testing 

--- 

## 3. Maintainability at Scale 

- Test volume grows rapidly with Shift-Left   
- → Must be: 
  - **Behavior-based (not implementation-based)** 
  - **Resilient to code changes** 

- Tests = **Production Code** 
  - Reviewed   
  - Refactored   
  - Maintained 

--- 

## 4. Robustness = Trustworthy Testing 

- Early testing without robustness → noise   
- Risks: 
  - False positives / negatives   
  - Loss of trust in tests   
- → Ensure: 
  - Deterministic results   
  - Stable execution   
  - Clear failures 

--- 

## ➡ Outcome 
**Faster iteration • Lower cost • Higher quality SDV software**
